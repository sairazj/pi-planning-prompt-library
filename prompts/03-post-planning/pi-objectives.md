# PI Objectives Prompts

Finalise and communicate PI Objectives after planning sessions complete.

---

## 1. PI Objectives Polisher

**Tool:** GPT, Rovo  
**When:** End of PI Planning day 2 — before management review

```
Improve the following PI Objectives so they are outcome-focused, clear, and measurable.

Current PI Objectives:
[paste raw objectives from planning]

For each objective:
1. Rewrite to focus on business outcome (not tasks or outputs)
2. Make it specific enough to know if it was achieved
3. Keep it to 1-2 sentences
4. Assign a Business Value score (1-10) based on strategic importance
5. Identify it as Committed or Stretch

Also check: do the objectives collectively tell a coherent story of what the team will deliver this PI?
```

---

## 2. ART PI Objectives Summary

**Tool:** GPT, Rovo  
**When:** RTE / Product Management — rolling up team objectives

```
Summarise the following team-level PI Objectives into an ART-level PI Summary.

[Team 1] Objectives:
[list]

[Team 2] Objectives:
[list]

[Team 3] Objectives:
[list]

Create:
1. A 3-5 sentence ART PI Summary for stakeholders
2. Key themes across all teams (group related objectives)
3. Total committed Business Value score
4. Highlight any objectives that are cross-team dependencies
5. Any gaps vs the PI Theme: [PI theme]
```

---

## 3. Objective-to-Metric Mapper

**Tool:** GPT

```
For each of the following PI Objectives, suggest 1-2 measurable success metrics.

PI Objectives:
[list objectives]

For each metric:
- Metric name
- How it is measured (data source)
- Target value or range
- When it will be measured (mid-PI check / PI System Demo / after PI)

Prefer leading indicators over lagging indicators where possible.
```

---

## 4. Stakeholder Communication Draft

**Tool:** GPT, Rovo  
**When:** Post-PI Planning — notifying stakeholders

```
Write a stakeholder update email summarising PI [number] planning outcomes.

Audience: [business stakeholders / executives / product leadership]

Include:
1. PI Theme and top-line outcome
2. Key features being delivered (3-5 highlights)
3. Teams involved and their primary objectives
4. Key dependencies or risks being managed
5. Innovation sprint focus
6. Next update date (mid-PI check)

Tone: confident, outcome-focused, brief (under 300 words).
```
